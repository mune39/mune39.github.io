# mune39.github.io

GitHub Pages 向けの静的HTMLと関連アセットを管理するリポジトリです。
トップページは意図的に空白としており、アプリやデモの公開一覧ではありません。

## 現在の構成

| 対象 | 役割・状態 |
| --- | --- |
| ルートの `index.html` | 空白のトップページ。`noindex,nofollow` を設定 |
| `robots.txt` | `User-agent: *` に対し `Disallow: /` を設定 |
| サブディレクトリ内のHTML・画像 | 個別用途のページと関連アセット。トップページからの案内なし |

個別ページのパスやURLは、このREADMEには掲載しません。
参照先を共有するときは、管理者が共有対象と共有範囲を確認してください。
検索除外設定や推測しにくいパスはアクセス制限ではなく、認証による非公開化を保証しません。

## 旧READMEとの違い

- 旧READMEの「桜木町 分配シミュレーター」は、当初トップページに置かれていた実装の説明です。
  2026年8月28日の変更で、検索・推測による露出を抑えるために個別パスへ移され、トップページは空白になりました。
  そのため、サイトのルートURLをシミュレーターの公開URLとして案内する記載を削除しました。
- PDF・CSV保存の説明は個別のシミュレーター実装に関するもので、トップページや全ページに共通する機能ではありません。
  保存UIはその後も変更されており、PDF生成には外部APIを呼び出す実装が含まれます。
  「外部依存なし」「PDF・CSV保存が通常のダウンロードで動作する」という一律の案内は行いません。
- 現在は複数のHTMLと画像を管理しているため、ルートの `index.html` の差し替えだけでは個別ページを更新できません。

## 更新時の扱い

更新対象のページと関連アセットを確認し、必要なファイルだけを変更してください。
トップページの空白表示、各ページの検索除外設定、`robots.txt` は、公開方針の変更が確認できるまで維持します。
個別ページへのリンクや一覧を追加する場合も、事前に共有範囲の確認が必要です。
